# 📝 タスク管理アプリ

シンプルで使いやすいタスク管理アプリです。React.jsで作成されており、ブラウザのローカルストレージにデータを自動保存します。

## ✨ 機能

- ✅ タスクの追加
- ✅ タスクの完了チェック
- ✅ タスクの削除
- ✅ 完了済みタスクの一括削除
- ✅ 自動データ保存（ローカルストレージ）
- ✅ レスポンシブデザイン
- ✅ モダンなUIデザイン

## 🚀 使用方法

### 開発サーバーの起動

```bash
npm start
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアプリを確認できます。

### ビルド

```bash
npm run build
```

## 🛠️ 技術スタック

- **React.js** - フロントエンドフレームワーク
- **LocalStorage** - データ保存
- **CSS3** - スタイリング（レスポンシブ対応）
