# Photoshop アートボード一括リネームスクリプト (JavaScript版)

## 概要
Photoshopのアートボードの名前を一括で変更するJavaScriptスクリプトです。AppleScript版よりも柔軟で高度な機能を提供します。

## ファイル構成
- `artboard-rename.jsx` - 基本的なリネーム機能
- `artboard-rename-advanced.jsx` - 高度なリネーム機能
- `README.md` - このファイル

## 基本的な機能 (artboard-rename.jsx)

### 1. 連番でリネーム
- アートボードを「Artboard 1」「Artboard 2」のように連番でリネーム

### 2. カスタムプレフィックス + 連番
- ユーザーが指定したプレフィックス（例：「Banner」）に連番を付けて「Banner 1」「Banner 2」のようにリネーム

### 3. 既存の名前を置換
- 既存のアートボード名から特定の文字列を検索して、別の文字列に置換

### 4. 既存の名前の前後に文字を追加
- 既存のアートボード名の前または後に文字列を追加

## 高度な機能 (artboard-rename-advanced.jsx)

### 1. 連番でリネーム（高度版）
- カスタムプレフィックス
- 開始番号の指定
- ゼロパディング（例：01, 02, 03...）
- 区切り文字のカスタマイズ

### 2. パターンマッチング（正規表現対応）
- 正規表現を使用した高度な検索・置換
- 大文字小文字の区別設定
- プレビュー機能

### 3. サイズに基づいてリネーム
- アートボードのサイズを分析して自動分類
- Small, Medium, Large, XLarge のカテゴリに分類

### 4. 縦横比に基づいてリネーム
- アートボードの縦横比を分析して自動分類
- 実際の縦横比を数値で表示（例：9-16, 16-9, 1-1）

## インストール方法

### 方法1: スクリプトパネルに追加（推奨）
1. スクリプトファイルを以下の場所にコピー：
   ```
   /Applications/Adobe Photoshop 2025/Presets/Scripts/
   ```
   または
   ```
   ~/Library/Application Support/Adobe/Adobe Photoshop 2025/Presets/Scripts/
   ```

2. Photoshopを再起動

3. `ファイル` → `スクリプト` → `artboard-rename` または `artboard-rename-advanced` を選択

### 方法2: 直接実行
1. Photoshopで `ファイル` → `スクリプト` → `参照...` を選択
2. スクリプトファイルを選択して実行

## 使用方法

1. **アートボードを含むPhotoshopドキュメントを開く**
2. **スクリプトを実行**
3. **表示されるダイアログでリネーム方法を選択**
4. **必要に応じて追加設定を入力**

## 高度な機能の使用例

### パターンマッチング
```
検索パターン: \d+  (数字を検索)
置換パターン: [数字]
結果: "Banner 1" → "Banner [数字]"
```

### サイズベースリネーム
アートボードの面積（幅 × 高さ）に基づいて自動分類されます：

**サイズカテゴリと範囲：**
- **Small**: 面積 100,000px² 未満（例：316×316px以下）
- **Medium**: 面積 100,000px² 以上 500,000px² 未満（例：316×316px ～ 707×707px）
- **Large**: 面積 500,000px² 以上 1,000,000px² 未満（例：707×707px ～ 1000×1000px）
- **XLarge**: 面積 1,000,000px² 以上（例：1000×1000px以上）

**リネーム結果例：**
```
小さいアートボード → "Small 1", "Small 2"
中程度のアートボード → "Medium 1", "Medium 2"
大きいアートボード → "Large 1", "Large 2"
特大のアートボード → "XLarge 1", "XLarge 2"
```

### 縦横比ベースリネーム
アートボードの縦横比を分析して、実際の比率を数値で表示します：

**認識される縦横比：**
- **1-1**: 正方形
- **3-4**: 3:4（縦長）
- **4-3**: 4:3（横長）
- **9-16**: 9:16（スマホ縦）
- **16-9**: 16:9（スマホ横）
- **2-3**: 2:3（縦長）
- **3-2**: 3:2（横長）
- **その他**: 一般的でない縦横比は実際の比率を表示

**リネーム結果例：**
```
正方形のアートボード → "1-1 1", "1-1 2"
スマホ縦のアートボード → "9-16 1", "9-16 2"
スマホ横のアートボード → "16-9 1", "16-9 2"
4:3のアートボード → "4-3 1", "4-3 2"
3:4のアートボード → "3-4 1", "3-4 2"
```

## 注意事項

- スクリプト実行前にドキュメントを保存することを推奨
- 大量のアートボードがある場合は処理に時間がかかる場合があります
- 正規表現を使用する場合は、パターンの正確性を確認してください

## トラブルシューティング

### スクリプトが表示されない場合
- Photoshopを完全に終了して再起動
- スクリプトファイルが正しい場所に配置されているか確認

### 実行時にエラーが出る場合
- アートボードが含まれるドキュメントが開いているか確認
- ドキュメントが破損していないか確認

### 正規表現エラーの場合
- パターンが正しい正規表現か確認
- 特殊文字が適切にエスケープされているか確認

## カスタマイズ

スクリプトはJavaScriptで記述されているため、必要に応じてカスタマイズ可能です。主なカスタマイズポイント：

- サイズカテゴリの閾値変更
- 位置カテゴリの追加
- 新しいリネーム方法の追加
- UIの改善

## ライセンス

このスクリプトは自由に使用・改変・配布可能です。
